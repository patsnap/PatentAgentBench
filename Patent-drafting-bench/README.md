# Patent-drafting-bench

中文 | [English](README.en.md)

Patent-drafting-bench 是一个评估大模型及智能体专利撰写能力的数据集，包含 **60 个测试任务**。模型需要依据技术交底书，按指定法域和语言撰写权利要求书、说明书及必要附图，最终交付一份 Word（`.docx`）文档。

评测关注模型能否将交底中的技术方案转化为完整、合理且有依据的专利申请文本，包括权利要求的完整性、清楚性、保护范围和从属布局，说明书的支持与公开，以及是否编造技术内容。每个任务包含通用评分标准与案例特异评分标准，可用于逐项人工审阅或 LLM judge 评分。


## 目录结构

```text
Patent-drafting-bench/
├── README.md
├── README.en.md
├── data/
│   └── test.jsonl
└── asset/
    ├── PD-0005_input.docx
    └── ...（共 60 份技术交底书）
```

`test.jsonl` 使用 UTF-8 编码，每行一个任务，共 60 行。`document_fields.input_file` 是**相对于本数据集根目录**的路径，例如 `asset/PD-0005_input.docx`，不是相对于 `data/` 的路径。

## 评分标准

每个任务提供通用评分标准和案例特异评分标准。通用标准评价权利要求的客体、单一性、清楚性、完整性、保护范围、从属布局及说明书支持，以及说明书的结构、实施例、公开充分性、表达和技术一致性。特异标准评价当前交底书中的技术特征、参数、实施方式和保护主题。

| 评分标准 | 全部任务的条目总数 | 每个任务的条目数 |
| --- | ---: | --- |
| 通用标准 | 900 | 15 |
| 案例特异标准 | 77 | 0～4 |
| **合计** | **977** | **15～19** |

每条标准包含判定条件、评分档位和正整数权重。档位分为 0、0.5、1，部分标准采用 0、1 两档。评审者根据产物选择对应档位，按权重计算百分制得分：

**得分 = 100 × Σ（权重 × 档位分）÷ Σ（权重）**
